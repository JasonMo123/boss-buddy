# 頭家夥伴 Boss Buddy

2026 和泰 AI 黑客松｜HINO 題目「HINO x GenAI：運用商用車車聯網大數據，發展商用車頭家的智慧夥伴」（主攻方向一：AI 節能夥伴）

> 會自己找問題、省下來才收費的車隊 AI 顧問。

## 一句話

中小車隊的頭家沒空看報表。頭家夥伴每天替每台 HINO 車做健檢：先用規則篩出異常，再由 AI 調查並排除錯誤線索，最後用 LINE 主動告訴頭家「哪台車、什麼問題、能省多少錢」。頭家回「不行」時，AI 會把原因當成限制條件重算。數據分不出原因時，AI 會設計實驗來找答案。收費方式是省下來才分成。

## 這個 repo 有什麼

| 資料夾 | 內容 |
|---|---|
| `分析/derive_metrics.py` | 從官方車聯網原始數據算出每台車的指標：日均用油、怠速時數與用油、行駛油耗、與同車型前 25% 的差距、故障碼 |
| `分析/build_model.py` | 產生「省油分成與導流收入試算表」（xlsx）。全部用 Excel 公式計算，含保守／基準／樂觀三種情境與敏感度排序 |
| `影片/make_demo.py` | 用程式產生 Demo 影片「王老闆的一個月」：畫面、英文配音、中英字幕 |
| `影片/soundtrack.py` | 用 numpy 合成背景音樂與音效，沒有使用外部音檔 |
| `影片/頭家夥伴_Demo.srt` | Demo 影片的中英字幕 |

**範圍說明**：這裡放的是**數據分析、商業試算，以及 Demo 影片的產生程式**。AI Agent 系統（探索者、調查員、反駁者、LINE 對話）目前是**設計階段**。影片裡的 AI 對話是依真實數據寫成的腳本，實驗結果標為「示意」。

## AI 架構（設計）

```
車機數據 ──► 規則監測 ──► 探索者 ──► 調查員 ──► 反駁者 ──► LINE 推播
(每台每天      (每天跑,     (LLM,每週    (LLM,自己決定   (LLM,專找反證:   (依「金額 × 可信度」
 約 1,400 筆)   比同型車)    找新問題)    查什麼)        雜訊、樣本太少)   決定講不講)
```

原則是「數據的部分不用 LLM」：

- 規則監測每天都跑，便宜，結果可以重現。
- 出現訊號時才交給 LLM 調查。
- 數學計算交給求解器和統計檢定。

| 工具 | 用在哪裡 | 為什麼選它 |
|---|---|---|
| Gemini Pro（Vertex AI） | 調查員、反駁者、探索者 | 長上下文可以一次讀完一台車的資料；用 Function Calling 讓模型自己決定查什麼 |
| Gemini Flash／Flash-Lite | 老闆對話、週報、訊號分類 | 便宜又快，適合次數多、難度低的工作 |
| BigQuery | 規則監測、同型車基準 | 大量時序資料每天用 SQL 跑，按查詢量計費 |
| OR-Tools、統計檢定 | 可行方案、實驗結果 | 數字要能重現，不讓 LLM 自己算 |
| LINE Messaging API | 推播與對話 | 頭家和司機本來就在用，不用另外裝 App |

## 主要數字（試算表基準情境）

| 項目 | 數值 |
|---|---|
| 車隊油耗下降 | 約 2.5%（保守 0.8%～樂觀 5.2%），已計入 60% 採納率 |
| 頭家淨省（一台 700 系列） | 約 1.8 萬元／年 |
| 和泰淨貢獻 | 約 3,492 元／台／年；推廣到 5,000 台約 1,750 萬元／年 |
| AI 與雲端成本 | 約 970 元／台／年 |
| 收費方式 | 省下金額分成 20%；每條建議只收 12 個月；按信賴區間下限計費 |

以上都是用比賽數據推算的量級：每台車只有 11～23 天資料，同一車型只有 4～10 台車。上線後要用連續資料重新估計。

## 重現方式

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# 1. 數據推算（需要官方原始數據，見下方說明）
.venv/bin/python -I 分析/derive_metrics.py
# 2. 試算表 → 分析/HINO省油分成試算.xlsx
.venv/bin/python -I 分析/build_model.py
# 3. Demo 影片 → 影片/頭家夥伴_Demo.mp4（需要 ffmpeg 與 Kokoro 模型，見 make_demo.py 開頭說明）
.venv/bin/python -I 影片/make_demo.py
```

## 資料與授權說明

- **官方競賽數據不在這個 repo 裡。** 主辦單位提供的車聯網數據、FAQ 與 iTRAQ 使用手冊僅限比賽使用，所以這些檔案，以及由它們推算出的每車數據與試算表，都列在 `.gitignore`。程式預期的檔案位置是 `原始官方資料/解壓原檔/HINO 競賽數據/…/output data_Hotai_20260511.xlsx`。
- 影片與程式中的車牌（ABC-xxxx）來自官方提供、已遮罩的數據。「王老闆」是虛構的情境人物。
- 英文配音用開源模型 [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)（Apache-2.0）在本機生成；配樂與音效以程式合成。
- 柴油價格等公開資料的來源網址寫在 `分析/build_model.py` 的假設表中。
